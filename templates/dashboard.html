Essential College Viva Defense Questions & Answers

1. What is the fundamental problem of Class Imbalance in fraud detection?

In our dataset, only 492 out of 284,807 transactions (0.17%) are fraudulent. Standard loss functions optimize for total overall accuracy. A model predicting every transaction as normal would trivially score 99.83% accuracy while failing 100% of its fraud-detection duties. Therefore, we use balanced class weights and evaluate on Precision, Recall, and F1-score.

2. What is Data Leakage and how did we prevent it?

Data leakage occurs when information from outside the training dataset (such as test set statistics) influences model training. We strictly performed our train_test_split before any scaling, fitting the StandardScaler solely on the training data, and then transforming the test set using those learned training parameters.

3. Why did we select Random Forest over Logistic Regression?

While Logistic Regression achieved high recall (91.84%), its linear decision boundary suffered from severe False Positives (1,386 false alarms, 6.10% precision). In contrast, Random Forest's non-linear ensemble decision trees captured fraud with 82.65% recall and 71.68% precision, cutting false alarms down to 32 and lifting the F1-score from 0.1144 to 0.7678.

4. Why are features V1 through V28 anonymized?

Real credit card data contains sensitive personal and financial identifiers (names, card numbers, locations, merchant codes). The original dataset providers applied Principal Component Analysis (PCA) dimensionality reduction to project the data into orthogonal eigenvectors (V1 to V28), preserving statistical variance without revealing sensitive cardholder details.
